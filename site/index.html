A learning POC, built in the open

An invite-only onboarding back office,
built to learn Salesforce's AI stack

Modeled on Stripe India's real application flow: a person applies, an AI + web crawler researches and scores them, a reviewer decides, approved businesses get provisioned and supported — and the whole build is documented as it happens.

Read the build log Apply for an invite

Brain vs. hands

Salesforce AI reasons over data it is given; it does not fetch the web. n8n fetches (scrapes) → hands clean text to Salesforce → Prompt Builder / Agentforce reason and write results back.

Salesforce AI stack

Prompt Builder scores each applicant; Agentforce agents converse with reviewers and applicants; Data Cloud grounds it all on unified data.

n8n crawling

The only thing that touches the open web. It scrapes, compresses to a summary, and hands it to Salesforce — never the other way around.

Native Salesforce reviewer UI

The reviewer's screen is real Lightning Web Components — page layouts, Dynamic Forms, and custom widgets, not a bolted-on external app.

Docs as code

Every phase gets a lesson: what I set out to do, what broke, how I fixed it. Drop a markdown file, commit, it's live.

Independent educational project — not affiliated with, endorsed by, or connected to Stripe. This is a learning exercise, hosted publicly so the journey is documented.
