Invite Only Portal

An invite-only onboarding back office modeled on Stripe India's real application flow, built to learn Salesforce's AI stack (Prompt Builder, Flow, Agentforce, Data Cloud) end to end. This page is the reference doc; Learn in Public in the sidebar is the dated build log behind it.

What it does

A person applies → an AI plus a web crawler researches and scores them → a human reviewer decides → approved businesses get provisioned and supported → the invited cohort's performance gets tracked over time (cancel vs. upsell). It's not a real product — it's a realistic-enough scenario to force every Salesforce concept a real onboarding system would actually need.

Architecture: the full flow

Salesforce AI reasons over data it is given; it does not fetch the web. n8n fetches (scrapes) → hands clean text to Salesforce → Prompt Builder / Agentforce reason and write results back → an approved applicant becomes a provisioned account.

Why I built this

I wanted to learn Salesforce's AI stack the way I'd actually use it on the job — not through isolated Trailhead modules, but by shipping one real, opinionated product end to end. Modeling it on Stripe India's public invite-only flow gave the build real constraints (a form, a review step, provisioning, retention) instead of a toy CRUD app.

Reading docs teaches vocabulary. It doesn't teach the fifteen small decisions — record type vs. object, Master-Detail vs. Lookup, permission set vs. profile edit — that only show up once you're modeling something with real constraints. Writing every gotcha down the moment it happened, in Learn in Public, was the fastest way to actually retain the platform instead of just recognizing the terms.
