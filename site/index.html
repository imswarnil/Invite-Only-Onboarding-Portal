Why I built this

I wanted to learn Salesforce's AI stack the way I'd actually use it on the job — not through isolated Trailhead modules, but by shipping one real, opinionated product end to end. Modeling it on Stripe India's public invite-only flow gave the build real constraints (a form, a review step, provisioning, retention) instead of a toy CRUD app. Every gotcha documented in the build log is something I hit for real, on this project, in this org.

Brain vs. hands

Salesforce AI reasons over data it is given; it does not fetch the web. n8n fetches (scrapes) → hands clean text to Salesforce → Prompt Builder / Agentforce reason and write results back.

Salesforce AI stack

Prompt Builder scores each applicant; Agentforce agents converse with reviewers and applicants; Data Cloud grounds it all on unified data.
