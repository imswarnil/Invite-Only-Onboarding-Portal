The Salesforce back office is only half the project — the public site (the one you're reading
right now) is the other half. This section covers how it's actually built (Jekyll: collections,
layouts, Liquid, no JavaScript framework required) and how it got its Stripe-inspired look: a
small set of design tokens, a type scale, and a handful of reusable components, not a CSS
framework.
