description: "Permission sets, field-level security, and the Guest User rules that make a public form safe."
---

Salesforce's permission model has sharp edges that only show up once real data (and real
strangers, via a public form) start touching your objects. This section covers why deploying
metadata doesn't grant access the way clicking through Setup does, why some fields refuse
explicit permissions, and the platform rule that makes a public "create-only" form possible at
all.
