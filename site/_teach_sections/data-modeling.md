Before any automation, AI, or UI work can happen, the data has to have a shape. This section
covers how the invite-only pipeline was modeled as Salesforce objects: what became a custom
object versus a record type, when a relationship should be Master-Detail instead of Lookup, and
how one field's valid values can depend on another.
