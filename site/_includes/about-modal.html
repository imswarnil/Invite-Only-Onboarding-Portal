{% include icon.html name="info" size=14 %}About this project

Invite Only Portal, in one page

A person applies → an AI plus a web crawler researches and scores them → a human reviewer decides → approved businesses get provisioned and supported → their performance gets tracked over time. It's a learning project, built to force every Salesforce concept a real onboarding system would actually need — not a real product.

Who this is built for

{% include icon.html name="users" size=15 %}Reviewer — Ravi

A GTM reviewer at a payments company, drowning in unqualified invite requests. Needs a fast, trustworthy way to see who's worth a look.

{% include icon.html name="users" size=15 %}Applicant

A small business or individual in India applying for early access — wants a simple form and a clear status on what's missing.

How n8n fits in

Salesforce's AI reasons over data it's given; it does not fetch the web. n8n is the only thing in this project that touches the open web — it scrapes what an applicant put on their own website and hands back clean text. Prompt Builder and Agentforce then reason over that text and write results back onto the record. Brain vs. hands.
